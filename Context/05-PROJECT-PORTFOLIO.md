## Evidence production — E sequence, P gate

Established pipeline: **Project → screenshots → short demo → case study → GitHub README → portfolio page.**

For each candidate: confirm context/role → inspect the real artifact → capture representative screens → show one complete workflow in a demo where appropriate → document decisions and limits → align README and portfolio → check public links and asset permissions.

Publish only when title, origin, role, maturity, summary, actual solution and appropriate evidence are complete. A prototype can be published as a prototype. If no public code exists, state why only when useful and provide another honest artifact. Scrub real personal records, credentials and private data from screens and demos.

## GitHub pack — E

For each important repository: README, About description, topics, folder structure, .gitignore, .env.example without real secrets, screenshots, feature list, stack, role/contributions, setup, architecture, challenges/solutions, lessons, roadmap, classification, appropriate license and pinned-repository description. Verify ownership before selecting a license. Aim to pin roughly 4–6 strong repositories after polish.
